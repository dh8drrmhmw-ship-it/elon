## 本垒棒球（`baseball/index.html`）

单文件的棒球资讯小程序演示，用手机浏览器打开即可。

- **美职棒数据**：比分、积分榜、球员榜、球队现役名单和教练团，直接从 MLB 官方接口 `statsapi.mlb.com` 实时读取。
- **连不上接口时**：美职棒部分显示示例数据，页面上会标出“示例数据”。例如在 claude.ai 的预览里，外部请求会被拦截。
- **球队主页**：30 支球队的简介、沿革、世界大赛冠军年份和队史传奇（资料截至 2025 赛季）。
- **球员主页**：基本资料、本赛季和生涯数据、最近 10 场比赛，来自 MLB 官方接口。
- **中文译名**：内置约 1180 位球员和教练的中文译名（覆盖 30 队现役名单），在球员页可以自己改，改动只保存在本机。
- **AI 中文战报**：Claude 根据比分和文字直播写中文战报，也能把英文文字直播翻译成中文。在 Claude 里打开时用观看者自己的 Claude 账号；在其他网页上需要在「我的」里填入自己的 Anthropic API Key，Key 只保存在浏览器本地。
- **文字直播中文**：按 MLB 官方播报的固定句式用规则翻译成中文，不需要 AI；认不出的句子保留英文。
- **得分球员**：比赛列表里显示每次得分的打者、局数和方式。
- **首页**：每场完赛自动生成中文战报（制胜分、得分过程、胜败投），以及最近 30 天的签约、交易等球员异动；科普文章保留。
- **比赛集锦**：比赛页和战报里播放 MLB 官方集锦视频（引用官方服务器，不转存），战报封面使用关键片段截图。
- **我的主队**：在球队页点「设为主队」或在「我的」里选择。头条顶部会固定显示主队的战绩、分区排名、最近一场和下一场比赛、最新战报和最近 30 天的异动，今日比赛里主队的比赛排在最前。只保存在本机。
- **自由球员追踪**：转会频道新增「自由球员」，分已签约（按日期）和待签（按 Statcast 综合能力排序），可以只看大联盟级别或只看主队，数据来自 MLB 官方自由球员名单。
- **年度奖项**：数据页新增「奖项」，包括世界大赛 MVP、两联盟 MVP、赛扬奖、新人王、最佳总教练、银棒奖和金手套；当年奖项公布前显示上一年得主。
- **球员 PK**：在球员页点右上角「PK」，搜索另一位球员（中文或英文名），对比两人的能力雷达、Statcast 百分位、本赛季和生涯数据。
- **其他联赛**：日职、韩职、中职、中国棒球联赛目前都是示例内容，只出现在各自的频道里，并标注“示例”；头条和「今日比赛」只放美职棒。

部署到 GitHub Pages 或任意静态网站后，就能看到实时数据。

### 部署到 GitHub Pages

`.github/workflows/pages.yml` 会在每次推送到 `main` 时运行 `scripts/build-pages.sh`。脚本把页面包装成完整网页，然后发布到 GitHub Pages。第一次部署前，需要在仓库的 Settings → Pages 里把 Source 设为 **GitHub Actions**。发布后的地址是 `https://<用户名>.github.io/elon/baseball/`。
