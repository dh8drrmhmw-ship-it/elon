## 本垒棒球（`baseball/index.html`）

单文件的棒球资讯小程序演示，用手机浏览器打开即可。

- **美职棒数据**：比分、积分榜、球员榜、球队现役名单和教练团，直接从 MLB 官方接口 `statsapi.mlb.com` 实时读取。
- **连不上接口时**：美职棒部分显示示例数据，页面上会标出“示例数据”。例如在 claude.ai 的预览里，外部请求会被拦截。
- **球队主页**：30 支球队的简介、沿革、世界大赛冠军年份和队史传奇（资料截至 2025 赛季）。
- **其他联赛**：日职、韩职、中职、中国棒球联赛目前都是示例内容。

部署到 GitHub Pages 或任意静态网站后，就能看到实时数据。
